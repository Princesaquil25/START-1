# START 1

START 1 is a career pathway web app for exploring career options, building
awareness of relevant skills and training, and identifying practical next
steps.

## Repository guidance

- [`AGENTS.md`](AGENTS.md) contains the instructions for AI-assisted
  development.
- [`requirements.md`](requirements.md) contains the product requirements and
  GIVEN/WHEN/THEN acceptance criteria.
- [`.github/copilot-instructions.md`](.github/copilot-instructions.md)
  redirects GitHub Copilot to the project rules.

## Application

The current application lives in [`START/`](START/). See
[`START/README.md`](START/README.md) for the available Node.js commands and
project structure.

The project uses Node.js 20 or newer. From the `START` directory:

```bash
npm install
npm test
```

Career information must be grounded in approved sources or content supplied by
the project owner. Suggestions should support exploration and should never be
presented as guarantees.
