# START

A minimal Node.js starter repository using CommonJS and Node's built-in test runner.

## Requirements

- Node.js 20 or newer

## Setup

```bash
npm install
npm start
```

## Development

```bash
npm run dev
```

## Tests

```bash
npm test
```
